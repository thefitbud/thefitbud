# FitBud brand fonts

**Satoshi** (Indian Type Foundry / Fontshare) — ITF Free Font License. Source: [Fontshare](https://www.fontshare.com/fonts/satoshi).

Bundled weights: 400, 500, 700 (`.woff2`) for native mobile via `expo-font`. Web loads the same family from Fontshare CSS (see `apps/mobile` web entry).

**Noto Sans Devanagari** — loaded via `@expo-google-fonts/noto-sans-devanagari` on native; Google Fonts on web.
