# QA reports

Every QA report lives here, so cloud agents can read it. The old `/workspace/qa/` folder existed only on one machine.

- **Name:** `QA-<ID or PR>.md`, e.g. `QA-PR37-round2.md`, `QA-AU1.md`.
- **Screenshots** for a task go in `docs/qa/<ID>/`, e.g. `docs/qa/BT3/privacy-1440x900.png`.
- **Specs** that cite a report must link the file here, never `/workspace/...`.
