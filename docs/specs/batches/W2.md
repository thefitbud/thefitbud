## Decisions
- **D-W2-1 Email provider: ZeptoMail** (India region API, `POST https://api.zeptomail.in/v1.1/email`, header `Authorization: Zoho-enczapikey <token>`, secret `ZEPTOMAIL_TOKEN` set by Firoz). Chosen over Resend and SES. Decided by Firoz, 30 Oct (v14 D-B3).
- **D-W2-2 Web hosting:** a web Worker `fitbud-web-<env>` serves the SPA with fallback to `index.html` and forwards `/api/*` to the API Worker through a service binding, stripping `/api` like the Vite proxy; same origin, no CORS, first-party cookies. Web on `app-staging.thefitbud.com` / `app.thefitbud.com`, API also on `api-staging.thefitbud.com` / `api.thefitbud.com`. Chosen over adding CORS. Decided by Firoz, 31 Oct (v14 D-B10).
- **D-W2-3 Client token refresh:** clients store `refreshToken` the same way each stores its token today, refresh before `expiresIn` and once on a 401 then retry once, sign out on refresh failure. Decided by Claude's recommendation adopted 31 Oct (v14 D-B6, AU1c).
- **D-W2-4 Logs:** staging observability at 100%, production `head_sampling_rate = 0.2`. Decided in v14 OB1 (Claude, 31 Oct).
- **D-W2-5 Live Activity scope:** local updates only (no APNs), cut-line Thu 12 Nov. Decided by Firoz, 31 Oct (v14 D-B7, C13).
- **D-W2-6 Live Activity is in the beta.** Decided by Firoz, 31 Oct 2026. Chosen over post-beta. v14's post-beta note (old line 108) is fixed to match D-B7 / C13. Tasks: LA1, LA1b, LA1c (W2), LA2, LA3 (W3).
- **D-W2-7 Domains.** Decided by Firoz, 31 Oct 2026: `api.thefitbud.com` = API Worker (D1, R2, queues); `app.thefitbud.com` = trainer web, served by a small web Worker (WD1); `api-staging.thefitbud.com` and `app-staging.thefitbud.com` = the same two for staging; `thefitbud.com` = landing page and sign-in redirect. No other trainer-web host is used. New task **X7** (S, sonnet) changes the mobile app's default trainer-web link (`apps/mobile/src/trainer/MoreScreen.tsx:13`).
- **D-W2-8 `MEDIA_PREFIX` in `Env`.** Decided by Firoz, 31 Oct 2026: I5 declares `MEDIA_PREFIX?: string` in `apps/api/src/types.ts`. It is the R2 key prefix per env (`staging/` on staging, unset elsewhere), applied only by I4b's `mediaKey()` at the R2 calls in `apps/api/src/routes/files.ts` (`:374` put, `:502` head, `:670` get).
