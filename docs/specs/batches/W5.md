## Guardrails for the Claude run (AGENTS.md, PLAN-v2 D-P2-19)
1. Merge commits only; never squash, rebase-merge, `--admin` or force-push; no direct push to `main`.
2. `ci` (and `qa-scripts` where it runs) green before merge; QA android/ios failures on a mobile PR are a stop, not a merge, from Z5-5 on.
3. One fresh reviewer per PR; its verdict is posted on the PR; the orchestrator never overrides a verdict. At most one fix round, then stop and report.
4. Every new assertion is mutation-checked, with the evidence in the PR body.
5. Edit `files_owned` only; a forced extra file is a stop and a question, not a silent change.
6. Shared and existing test files are add-only.
7. Diagnose-first tasks (Z5-5, Z5-22) post the cause before any fix commit.
8. Stop and report when a brief contradicts the code, another brief or a decision; verify the file citation first (D-P2-19 (5)).
9. No remote, deploy or migration commands; no secrets. Implementers don't wait on CI (D-P2-19 (1)).
