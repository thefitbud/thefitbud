## Outcome
The trainer sees every Attention section without scrolling through the one above it: tap a pill to jump to a section, each section shows its first rows with "See all", headers collapse, and rows line up the same way in every section.

## Context
- Diagnosis #19, #20, #21. **D-W14-25** (pattern and why: one scroll container, no nested scroll panels), D-W14-27 (avatar → profile), D-W14-24 (back), **D-W14-28** (mock gate: Z14-17 approved). Frame file names above are the planned ones; use the approved files listed in `docs/design/mockups/z14-17/README.md` if they differ.
- Today: every section is fully expanded in `Screen`'s `ScrollView` (`AttentionTab.tsx:752-935`, `NeedsYouView.tsx:240-321`); the summary tiles are display-only (`NeedsYouView.tsx:182-238`); the row's trailing control has no fixed width (`:584-591`).
- Build on Z14-21's `ListScreen` (`SectionList`, `scrollToLocation`) and Z14-19's `ClientAvatar`. Data loading and snapshot paint stay as Z14-3 left them; the review sheet stays as it is until Z14-23.
- Four screens: Attention top, Attention scrolled (sticky pills), a collapsed section, the section "See all" screen.

## Acceptance criteria
- [ ] Attention is one `SectionList` (header and summary as the list header); no `ScrollView` inside it and no inner scrolling panel anywhere on the page.
- [ ] The summary tiles are buttons ("Jump to Missed, 2"): a tap scrolls so that section's header sits under the sticky pill row; a tile with 0 is shown muted and not pressable.
- [ ] Once the tiles scroll away, a compact pill row sticks under the title; the pill of the section in view is highlighted (driven by `onViewableItemsChanged`); tapping a pill jumps as above.
- [ ] Each section shows its first 3 rows; more than 3 adds a "See all {n}" row that opens `SectionAllScreen` (title "{Section} · {n}", the same rows, swipe and actions as on Attention, avatar → profile). Back (on-screen and Android) returns to Attention at the same position.
- [ ] A section header tap collapses or expands it (chevron, `accessibilityState.expanded`); the state lasts for the session; a collapsed section still shows its count; pills still jump to it (and expand it).
- [ ] One row template for all sections: avatar top-aligned, text column start fixed, age right-aligned on the name line, the trailing control in a fixed slot (button or chevron centred), chips on their own line, identical inside and outside `SwipeActionRow`; checked at font scale 1.0 and 1.3 and at 360 dp width.
- [ ] Tapping the avatar or name opens the client's profile (`ClientAvatar`); the row's Review/Reply still opens the review or the ask.
- [ ] Loading, empty ("all caught up"), offline and error states keep their current frames (TM-01d/e/f/g).
- [ ] The section for acknowledged items is titled "Noted, still open" (was "Reviewed, still open", D-W14-29); its rows say "Noted · {time}".
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.
