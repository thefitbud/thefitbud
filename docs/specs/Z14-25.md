## Outcome
In the trainee app, Android back closes the open sheet or goes to the screen the client came from, from Workout, Diet, Progress or More goes to Today, and only leaves the app from Today. On iOS every pushed screen can be swiped back from the left edge and shows the same header back. A second-level screen (Account → Password) goes back to its parent, not to the tab.

## Context
- Diagnosis #28 (and #17 for the trainer side). **D-W14-24** (confirmed by Firoz 24 Nov 2026: "Yes fix the back in trainee app too"; the trainee root tab is Today).
- Today: only `ActiveWorkoutScreen.tsx:479` handles back; everything else leaves the app on Android. The overlay is a single slot (`TraineeShell.tsx:247` `useState<TraineeOverlay | null>`), closed with `onClose={() => setOverlay(null)}` (`:944`, `:1061`, `:1102`), so every overlay's Back goes to the tab, even from a screen opened from another overlay (`TraineeOverlay.tsx:414-424` Account → Password/Privacy/Language/Past coaching). Only Delete account hand-codes Back → Privacy (`:413`).
- Use the shared `useHardwareBack`, `PushedScreen` and `HeaderBack` from Z14-18 unchanged (if they need a change, stop and note it; do not edit Z14-18's files).
- Z14-2 keeps visited tabs mounted; render overlays over the mounted tabs (and over the overlay below) so the iOS swipe reveals the real previous screen.

## Back targets (D-W14-24, trainee)
| Where the client is | Back does |
|---|---|
| Today tab (no overlay, no sheet) | Leaves the app (Android default) |
| Workout, Diet, Progress or More tab | Shows Today |
| Any open sheet or dialog (log sheets, finish, ask coach, meal sheets, sign-out confirm, sync, ended coaching) | Closes that sheet only (existing `onRequestClose`; add where missing) |
| Active workout | Its own handler stays (`ActiveWorkoutScreen.tsx:479`, Z14-8's file); this task does not change it |
| An overlay opened from a tab | That tab, as it was left (scroll kept) |
| An overlay opened from another overlay (Account → Password, Privacy → Delete account, Today → meal → food search…) | The overlay below it |
| Opened from a push or deep link | The same rule; with nothing below, the tab the link set, else Today |
| Check-in with typed answers | The check-in's own discard question (its "Close" calls the same function) |
