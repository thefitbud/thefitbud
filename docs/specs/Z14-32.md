## Outcome
After a workout the trainee can type a short note for their coach next to the 1–10 rating, see it on View summary, change it for 48 hours in the same sheet as the rating, and the trainer reads it on that session's screen. Z14-12 built everything around the note except the field itself.

## Context
- **D-W14-34**, D-W14-10, **D-W14-20**. The API change is Z14-31 (merge first): `PATCH /workouts/executions/:id/feedback` and the `workout.feedback` sync mutation take `{ rpe?, note?, recordVersion }`; the execution read returns `sessionNote`.
- Frames W-17a2 ("Note for Rahul", placeholder), W-17c ("Your rating and note" group with one Change), W-17c2 (sheet: 1–10 grid and the note, Save/Cancel), W-17c3 (closed window). Build exactly these frames.
- **Wording (Firoz, 25 Nov 2026, D-W14-37): first names only, no pronoun guessed from anywhere.** The W-17a2 placeholder reads "Anything he should know?"; build "Anything {Coach first name} should know?" instead and record it as a frame deviation.
- Z14-12's header comments in `WorkoutSummaryScreen.tsx` (about `:44-50`) say the note is not built and that nothing may imply a saved note; update them. `rpeRating.ts` already holds a rating until the finish has synced (`RATING_HELD_MESSAGE`); the note rides with it (a restart still loses a held rating, which Z14-37 fixes).

## Acceptance criteria
- [ ] After Finish, the summary shows the rating grid and a **Note for {coach first name}** field (multiline, 500 characters, counter only near the limit), optional unless the plan requires a rating (then only the rating blocks Save, as today). One **Save and share with {coach}** sends rating and note together; nothing is sent twice.
- [ ] **View summary** on a finished workout shows "Your rating and note": the rating, the note text (or nothing when empty), and one **Change** while `feedbackEditableUntil` is in the future. Change opens W-17c2: the grid and the note, Save/Cancel; Save sends only what changed; Cancel discards. After the window: no Change and the W-17c3 line "Ratings and notes can be changed for 48 hours after a workout." (read-only note still shown).
- [ ] Offline or finish still queued: the pick and the note are held with the neutral message (`RATING_HELD_MESSAGE` wording extended to "Your rating and note will be saved when this workout is sent." when a note is present) and sent once the finish has synced, with the version read from the server (the Z14-12 rule: never guess the version). A refusal (window closed, conflict, other) shows the existing plain words, keeps the typed note on screen so it is not lost, and offers Try again.
- [ ] A 409 conflict re-reads once and retries only when the server's rating **and note** are the ones last seen; otherwise the conflict is shown with the server's values (no silent overwrite).
- [ ] Trainer session screen: a "Note from {First}" card under the metrics, only when a note exists, same card style as the existing note cards, text wraps and is selectable, first name only. Nothing for an empty note.
- [ ] Pressing the hardware/iOS back while a live workout is open does what Z14-25 specified; a new test mounts the **real** `WorkoutTab` inside `TraineeShell` (with a per-test timeout, not the shared default) and proves Back on a live workout leaves Today in place and never exits.
- [ ] `F03-first-workout.yaml` summary steps type a note and save it (selectors by `testID`; add stable testIDs `workout-note-input` and `workout-note-save` if needed); no other flow edits.
- [ ] Light and dark, 393×852 and 360×800, large text: nothing clipped; the note field stays visible above the keyboard.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.

## Decide-and-note
1. **One sheet for both (recommended, as drawn):** the Change sheet edits rating and note together; do not add a separate "Edit note" entry.
2. **Whitespace-only note (recommended):** treated as empty (clears an existing note); do not show a validation error.
3. **Where the trainer sees it:** the session screen only (Activity carries "left a note" from Z14-31). Do not add a notification.
