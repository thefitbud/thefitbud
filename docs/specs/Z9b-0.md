## Outcome
`main`'s `e2e` and `banned-strings` jobs get past "Install Playwright browsers" again, so main can go green.

## Context
- Main has been red since #373 (11 Nov 2026). `ci` passes. `banned-strings` fails, and `e2e` is cancelled at its 45-minute timeout, in `playwright install --with-deps`: apt on the `ubuntu-latest` runner (Ubuntu 26.04 "resolute") gets "Temporary failure resolving" for azure.archive.ubuntu.com, archive.ubuntu.com and security.ubuntu.com (exit code 100). It failed the same way on a re-run about 1.5 h later, so this is not a one-off flake. The last green main run (#370, 12:05 UTC) predates it.
- **Fix (as built, 11 Nov 2026):** pinning `ubuntu-24.04` was tried first and failed the same way ("noble"), so the problem is the runners' DNS for the Ubuntu mirrors, not the image. The two jobs now run in `container: mcr.microsoft.com/playwright:v1.64.1-noble` (the tag matches the locked `playwright@1.64.1`), which already carries the system dependencies and the browsers, so the install step drops `--with-deps`. Don't skip or weaken any test; WebKit still runs.
- `qa.yml` (optional workflow) has the same install step. Left as a follow-up, outside this file.
