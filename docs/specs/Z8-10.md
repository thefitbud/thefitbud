## Outcome
Trainers add standard questions with fixed wording and pick which measurements to ask for; their own questions are marked "not charted"; **standard question keys survive edit/fork-and-save**.

## Context
- Covers master-list (v13) items W5a. Everything the implementer needs from those rows is pasted here.
- Standard keys from Z6-6 / D-W6-17: `weight`, `waist`, `hips`, `chest`, `arm`, `thigh`, `photo_front`, `photo_side`, `photo_back`, `energy`, `sleep_quality`, `stress`, `hunger`, `notes`. No body fat. v2 fields are optional; never invent a wellbeing "OK". Fork of the global form copies `GLOBAL_CHECKIN_FORM_VERSION_ID`, not blindly `latestVersionId` (already shipped in Z6-6 / #286).
- **Key preservation (D-P2-24 / D-W8-6):** `CheckinFieldDraft` has no `key`; `draftsFromCheckinFields` drops it; `buildCheckinFields` rebuilds without it. Editing a keyed v2 fork then produces unkeyed questions and progress charts lose continuity. Preserve the 14 standard keys; custom questions may stay unkeyed. Must land before trainers edit or fork-and-save v2 forms. **Do not rebuild the builder beyond this.**
- Design guide for every UI task: `docs/design/README.md` (v3 rules and the frame index), `docs/design/DESIGN-NOTES.md` (palette, type, spacing, components, data and time), `docs/design/DECISIONS-21OCT.md`, and the screen spec in `docs/spec/`. Dates read like "Wed 21 Oct" (never ISO), enums always go through `labelFor` (`packages/core/src/labels.ts`), touch targets are at least 44 pt / 44 px, counts and kcal use tabular numbers.
- Design-review step (W11 Z11-1): after capturing, run `node scripts/qa/visual/diff.mjs --task <ID>` on the captures and attach the generated `docs/qa/<ID>/design-review.md` to the PR. A frame difference the spec does not explain is fixed or listed in the PR as a follow-up, never silently left. **Until Z11-1 is on `main`** (it now runs in W11, after this batch — PLAN-v2 D-P2-7), skip the script: the reviewer's visual check compares the captures with the frames side by side, and the PR says "design-review tool not on main yet".
