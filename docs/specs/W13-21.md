## Outcome
Each row in the Overview's "Needs attention" card says which meal or workout and which day, like the review panel's title, so rows of the same type can be told apart.

## Problem
Five rows read "Overdue meal", "Meal change", "Skipped meal", "Skipped workout", "Overdue check-in" with only "Open 4 h ago" under them (`qa-captures/w13-6/W-03-client-overview-1440x900.png`). The panel opened from the first row is titled "Overdue meal · Dinner · Tue 24 Nov". With two meals missed the card shows two identical lines. Frame W-03 draws a title line and a detail line ("Lower B on Sat and Lower A on Tue…").

## Acceptance criteria
- [ ] Row title is the same string the review panel uses for that item (type, meal or workout, weekday and date: "Overdue meal · Dinner · Tue 24 Nov"); the existing "Open 4 h ago" age line stays as the detail line. Use the list item's own fields; if the list endpoint does not carry the meal/workout subject, reuse the summary text it has and record in the PR which fields were missing. No new API call beyond the one W13-6 already added.
- [ ] Row order is unchanged (Critical first, then newest), and the review panel opened from a row uses the same order (W13-13 owns the drawer side; assert the pager's "n of m" equals the row position in an e2e).
- [ ] Titles truncate with an ellipsis at one line only if they must; the Review Quiet button and severity pill never move or clip at 1024.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, the web e2e pass.

## Tests to add
- Unit: two missed-meal items with different meals render two distinguishable titles; e2e: click the second row, the modal shows "2 of n".
