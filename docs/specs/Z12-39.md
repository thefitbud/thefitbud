## Outcome
On a day after today (in the trainee's zone) the trainee sees the plan with no way to log it, and the server refuses any future-dated log; past days stay loggable as late logs.

## Context
- Finding 5; D-W12-7; flow F29. TR-06c and TR-07f stay as they are (past days, edit-window rules).
- Server: reject meal, workout, set and measurement logs whose civil date is after the trainee's today in their stored zone; 422 `FUTURE_DAY` with a static message (AGENTS.md API errors). Use the CU17 zone resolver (`packages/core/src/zone.ts`), no `"Asia/Kolkata"` literals. Synced offline logs go through the same guard in `routes/sync.ts`.
- Touches the local D1 in its server part: serialise (D-W12-19).
