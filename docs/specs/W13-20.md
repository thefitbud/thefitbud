## Outcome
The nutrition builder's calories never mix days, and the small controls in the property panes are real, labelled, tappable controls.

## Decision: "Every day" calories (D-W13-29)
Two fixes were possible: count only the meals that apply every day, or label the mixed total. The simpler correct one is to **count only the meals that apply every day** in the "Every day" view, and say so only when it matters. The plan's real day totals are the Training days and Rest days views.

## Problem
1. **"Every day" view mixes days.** The tile "1,745 kcal · Protein · Carbs · Fat" on the Every day tab counts weekday-only meals too (`MealsPane.tsx` ~73, 126, 159; `MacroTiles.tsx`), so the total belongs to no actual day (pre-existing; `qa-captures/w13-3/W-154-1440x900.png`, `client-plan-nutrition-1440x900.png`).
2. In the workout property pane the **"Clear"** link under Reps is tiny, grey and unlabelled in context (`ExerciseProperties.tsx` ~158-161; `qa-captures/w13-3/W-152-1024x1366.png`). It needs to read as an action ("Clear reps") and be a 44 px target on iPad.
3. **"Open food library"** under the meal cards is a small underlined link (`MealsPane.tsx` ~425; `W-154-1024x1366.png`): make it a Quiet small button or a link with a 44 px target.
4. Meal property pane: the first food's quantity box sits beside its unit select, the second wraps below it and pushes "Remove" aside, because the long unit name does not fit (`W-154-1024x1366.png`). Lay every food row out the same (select full width, quantity and Remove on one row beneath).
5. Client plan builder header reads "Fat loss · Phase 2  · Rohan Mehta" with an extra space before the dot (`client-plan-nutrition-1440x900.png`): one separator style, one space each side.

## Acceptance criteria
- [ ] Every day tab: tiles count only meals that apply to all seven days (meals marked weekday-only, training-day or rest-day are excluded). When at least one listed meal is excluded, a quiet line under the tiles says "Counts the meals that apply every day." Training days and Rest days tabs unchanged.
- [ ] Items 2 to 5 fixed; behaviour unchanged (clear reps still clears); test ids kept.
- [ ] 44 px targets at 1180 and 1024 for the controls above; no clipping.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, the web e2e pass.
