- [ ] New `src/lib/noGenderGuess.test.ts`: reads every `.ts`/`.tsx` under `apps/trainer-web/src` (excluding tests) and fails if one imports `possessivePronoun` or defines a function named `pronoun`, `objectPronoun` or `possessive` that returns "his", "her", "him" or "she". It lists the offending file. (Only the guard reads the source; `packages/core/src/pronouns.ts` stays, the app may still use it and is out of scope.)
- [ ] Copy otherwise unchanged; tests that asserted a pronoun updated; `pnpm lint`, `pnpm typecheck`, `pnpm test`, the web e2e pass.
