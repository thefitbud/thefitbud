## Outcome
Every trainer list that can grow (check-ins, a client's coach notes, coach asks) can be read a page at a time with a cursor, without changing what existing callers get.

## Context
- Diagnosis #18. **D-W14-26** (paging rules). `GET /clients` and `GET /activity-feed` already page by cursor (`routes/clients.ts:145-167`, `routes/activity-feed.ts:207`, `lib/cursor.ts`); copy that pattern.
- Today: `GET /checkins/inbox` (`routes/checkins.ts:1400-1460`) and `GET /checkins/relationships/:id/notes` (`:1025-1062`) return every row with `nextCursor: null`; coach asks are unpaged.
- Trainer web and the Attention screen call these without a limit and need the full set (Attention counts); that must not change.
- The trainer app has no notifications list, so `GET /notifications` is not part of this task (Diagnosis #18).

## Acceptance criteria
- [ ] Each of the three endpoints accepts optional `limit` (1–50) and `cursor`. With **no `limit`**, the response is exactly as today (all rows, `nextCursor: null`). With a `limit`, it returns at most `limit` rows in the current order and a `nextCursor` (or `null` at the end).
- [ ] Keyset cursors on the existing sort keys plus `id` as the tie-breaker (stable when rows are added between pages, no duplicates or gaps); an unknown or tampered cursor gets the existing friendly 400 used by `GET /clients`.
- [ ] Check-in inbox accepts an optional `segment` (`to_review` | `overdue` | `reviewed`) so each Check-ins tab segment pages on its own; with no `segment`, unchanged.
- [ ] Coach asks keep their `status` filter; paging works per status.
- [ ] Query-count tests: one page costs a fixed number of queries regardless of total rows (fixture with 120 check-ins, 80 notes, 60 asks).
- [ ] Authorization unchanged (trainer sees only their relationships; ended clients read-only); `authorization-matrix.test.ts` passes.
- [ ] Contracts and the api-client change additively only; trainer web e2e and mobile tests pass unchanged.
- [ ] `pnpm build:packages`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, trainer-web e2e pass.
