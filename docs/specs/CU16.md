## Outcome
The nightly QA workflow's `android` job builds the staging APK and runs the Maestro flows again, instead of failing while bundling JS. **Top priority in W3b; runs first, alongside CU1.**

## Context
- Evidence: QA run https://github.com/thefitbud/thefitbud/actions/runs/41626577130 (3 Nov 2026, 16:49 IST; run head `d754116`). Job `android`, step "Build the staging APK", Gradle task `:app:createBundleReleaseJsAndAssets` failed with `Error: Cannot find module 'metro-resolver'`; require stack: `apps/mobile/metro.config.js` ← `import-fresh` ← `cosmiconfig` ← `metro-config@0.81.5/src/loadConfig.js` ← `@expo/cli@0.22.28` `exportEmbedAsync`. Every other job passed (web 42/42, api 99/101 with 2 skipped, unit 1795/1795, seed-reset OK).
- Cause: `apps/mobile/metro.config.js:2` does `require("metro-resolver")`, but `apps/mobile/package.json` does not declare it. Under pnpm's isolated layout an undeclared package is not resolvable from `apps/mobile`; it only worked where something else made it reachable (EAS installs differently, and local runs through pnpm's bin shim set `NODE_PATH`, see the `.npmrc` comment).
- The lockfile resolves exactly one Metro: `metro@0.81.5` and `metro-resolver@0.81.5` (Expo SDK 52 `~52.0.46`, `react-native` 0.76.9).
- **Preferred fix:** add `"metro-resolver": "0.81.5"` (matching the resolved `metro`; use `~0.81.5` only if `npx expo install --check` asks for a range) to `apps/mobile/package.json` `dependencies` and update the lockfile. **Allowed alternative:** resolve it through a guaranteed path, e.g. `require(require.resolve("metro-resolver", { paths: [path.dirname(require.resolve("metro/package.json", { paths: [require.resolve("expo/package.json")] }))] }))`, documented in a comment. Do **not** change `.npmrc` hoisting (AB1's `public-hoist-pattern` must stay exactly as is).
- D-W3b-2: CU6 also changes `apps/mobile/package.json` and the lockfile, so CU6 runs after CU16.
- **EAS builds pass today; keep them passing.** The fix must not add a second Metro version or change what EAS resolves.
