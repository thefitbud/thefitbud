## Outcome
No screen in these files guesses a client's gender. D-W14-37 (Firoz, 25 Nov 2026) set the rule for the app and for the client page's onboarding text; W13 left trainer web's Settings and modals on it.

## Problem
- Client Settings > Client details prints "Reminders follow **his** time" and the End coaching card "Rohan keeps **his** account and history." (`qa-captures/w13-10/W-209-1440x900.png`, `W-209-ipad-1024x1366.png`, `nf-danger-zone-1440x900.png`). The strings come from `possessivePronoun(traineeProfile.gender)` in `ClientSettingsPage.tsx` (~210, 381, 609).
- The same inference is in `RemindersSection.tsx` (~87, 344 "never in {her/his/their} quiet hours"), `CoachingLifecycleModals.tsx` (~36, 89, 135, 136, 151: "keeps her account", "His history", "update his intake"), `NoteComposer.tsx` (~91, 371-372: "{First} will see this on {pronoun} Today screen"), `CoachAskDrawer.tsx` (~44, 120, 207, 359, 378: "Opened WhatsApp from {pronoun} log", "ask her to …"), `AssignPartialFailureModal.tsx` (~28, 73, 77) and `ResponsivenessPanel.tsx` (~65).

## Acceptance criteria
- [ ] None of the files above imports `possessivePronoun` or prints he/she/his/her/him/them chosen from gender. Use the first name or neutral wording:
  - "Reminders follow Rohan's time"; "Rohan keeps the account and history."; "never in Rohan's quiet hours".
  - NoteComposer, same as the app (Z14-24): "{First} sees it on Today and gets one notification." / "{First} can see this on Today." as the existing visibility states require.
  - CoachAskDrawer: "Opened WhatsApp from {First}'s log", "From {First}'s {log label}", "Ask {First} to …".
  - Lifecycle modals and AssignPartialFailureModal: "{First}'s history", "{First}'s intake answers", "{First} can still see and log the sessions."
- [ ] If the first name is unavailable use the neutral noun already available in that sentence ("the client"), never "their" built from a pronoun helper.
- [ ] Copy is otherwise unchanged; every `data-testid` kept; tests that asserted a pronoun are updated to the first-name copy.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test`, the web e2e pass.

## Tests to add

- Mutation check: reintroduce one pronoun and see the test fail.
