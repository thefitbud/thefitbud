## Outcome
Trainer web (and later mobile) can load everything the approved exercise detail page shows in one request: the exercise, its drawings (from Z14-48), numbered steps, coaching cues, common mistakes, and related exercises grouped as easier, harder and swap-for.

## Context
- Firoz approved the exercise detail mock on 28 Nov 2026 (https://claude.ai/artifact/9dVBbZfqom5th3jdg9sCnc), minus the per-exercise credit line (**D-W14-51** approved, **D-W14-53**). The food detail page stays deferred (**D-W14-54**).
- The data already exists in D1: `exercise_library_instructions` (kind `step` | `cue` | `mistake`, `position`, `text`, `lang`) and `exercise_library_relations` (kind `regression` | `progression` | `alternative` | `home_alternative` | `gym_alternative`). Neither is in any contract today. There is no single-exercise GET route; only list, create, PUT and DELETE exist in `routes/libraries.ts`.
- Z14-48 (#616) adds `media[]` and `thumbnailUrl` to exercise items. Start after it merges, because both tasks edit `libraries.ts`.

## Acceptance criteria
- [ ] `GET /libraries/exercises/:itemId` for a trainer returns `{ item, steps: string[], cues: string[], mistakes: string[], related: { easier: Rel[], harder: Rel[], swapFor: Rel[] } }`, where `item` is the existing exercise schema (with Z14-48 media) and `Rel = { id, name, thumbnailUrl | null }`. Mapping: `regression` → easier, `progression` → harder, and `alternative`, `home_alternative` and `gym_alternative` → swapFor, deduplicated by id and ordered by name. Steps, cues and mistakes come in `position` order, `lang = 'en'`.
- [ ] Ownership: a trainer can read global exercises and their own; another trainer's exercise returns 404 `LIBRARY_ITEM_NOT_FOUND` (the same code the PUT uses). Related rows pointing at another trainer's private exercise are left out. Archived related exercises are left out.
- [ ] One query per table (item, media, instructions, relations plus related names and thumbnails), with no N+1. Static error text.
- [ ] A trainer-owned exercise with no instructions returns empty arrays; the client hides those sections.
- [ ] Contract, api-client and authorization tests: global item, own item, other trainer's item (404), unauthenticated (401), ordering and grouping, and a private related exercise excluded.
- [ ] `pnpm lint`, `pnpm typecheck` and `pnpm test` pass.
