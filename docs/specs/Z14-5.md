## Outcome
Every native change W14 needs lands in one PR so Firoz makes one build pair: a SQLite device store, a photo picker, a date picker, a working lock-screen Log on iOS, and an Android live-workout notification that matches iOS and shows on the lock screen.

- Diagnosis #1 (device store), #9, #12 (photo), #14 (DOB). D-W14-7, D-W14-11, D-W14-12, D-W14-17. Same pattern as Z12-57: one native PR, every other W14 task is JS-only and builds on this.
