## Outcome
Frames 160–161 (trainer Progress) get a series for any standard key over 4 weeks, 12 weeks, all time or a custom range, and can compare two keys.

## Context
- Covers master-list (v13) items B2c. Everything the implementer needs from those rows is pasted here.
- Endpoint: `GET /progress/relationships/:id/metrics?keys=weight,waist&range=4w|12w|all|custom&from&to`. Points: `{ localDate, value, checkinId }`; ratings return integers. Compare = two keys in one call.
- Sources: check-in answers by key (v2) and measurements already stored (`measurements`, `apps/api/src/db/schema.ts:1092`), merged by date, check-in wins on the same day.
- No percentages or trend arrows; the response carries values only.
