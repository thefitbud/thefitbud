## Outcome
On trainer web, every exercise thumbnail in the Library, template builders and the exercise properties pane shows the real drawing. An exercise with no drawing, or whose image fails to load, shows one neutral line-drawn dumbbell icon instead of a coloured tile. Foods show no thumbnail at all, and their rows close up neatly. Drawings are credited once on the Credits and licences page, not on each screen (D-W14-53).

## Context
- Firoz, 28 Nov 2026 (**D-W14-49**, **D-W14-50**, **D-W14-52**, **D-W14-53**). `LibraryThumb` today paints a gradient from a hash of the name (`components/ui/LibraryThumb.tsx`), used in the Library tables, builder library lists, session editor, exercise and meal properties, and the meals pane.
- Z14-48 adds `media[]`, `thumbnailMediaId` and the image route (or `thumbnailUrl`) to exercise library items. Use the api-client; no hand-written fetch.
- Credits rule: `docs/spec/credits-and-licences.md`.

## Acceptance criteria
- [ ] **Exercise thumbnail:** `LibraryThumb kind="exercise"` takes the item's thumbnail source. It renders an `<img>` (lazy, decoding async, `alt=""` since the name sits next to it, object-fit contain on a white/neutral tile so the line drawings read). Size and radius are unchanged from today's tile, so the layout doesn't move.
- [ ] **Fallback (D-W14-52):** with no `thumbnailMediaId`, or on image `error`, render a neutral tile with the lucide `Dumbbell` line icon (MIT, already a trainer-web dependency; if not, use an inline SVG) in ink-3. Never a coloured gradient. The fallback has no text, is `aria-hidden`, and looks the same for every exercise.
- [ ] **Foods (D-W14-50):** no thumbnail element at all in food rows, meal rows, the meals pane and meal properties. Remove the slot, not just its contents, and keep row alignment and the 44 px row heights. Delete `libraryThumbStyle` if nothing else uses it.
- [ ] **No credit lines on exercise screens (D-W14-53):** drawings are credited once on the existing Credits and licences page (`/credits`). Do not add a credit line to rows, builders or the properties pane. Check that `/credits` lists Everkinetic, CFCF, wger.de and hans with their licences, as `docs/spec/credits-and-licences.md` says; if it does not, say so in the PR (the page is outside files_owned).
- [ ] No raw keys, ids or error text on screen. A failed image is silent apart from the fallback, and is reported once per session through `reportError` with no URL.
- [ ] Captures at 1440×900, 1180×820 and 1024×1366 under `apps/trainer-web/qa-captures/z14-49/`: Library exercises, Library foods, workout builder with the library list open, exercise properties, meal builder, and one exercise with no drawing (fallback). Run the W13 `textProblems()` checks.
- [ ] e2e: exercise rows render an `img` for a seeded exercise with media, and the fallback icon for one without; food rows have no thumbnail element. `pnpm lint`, `pnpm typecheck`, `pnpm test` and the banned-strings scan pass.
