## Outcome
The app can record how hard a workout felt after it is finished, and can attach a real photo to a meal that is already logged, with both actions safe to retry.

## Context
- Diagnosis #4 and #12. D-W14-10 (RPE editable by the trainee for 48 h after finish, read-only after), D-W14-11 (attach endpoint).
- The coach already edits a finished execution's RPE (`workouts.ts` near `:2273`, 7-day limit); reuse its validation and audit path, not its authority.
- Meal confirm accepts `photoIntent.mediaAssetId` at log time only (`meals.ts:797-931`); the upload flow is `files.ts:101` (create) → `:262` (PUT bytes) → `:409` (complete).

## Gap list
- No trainee endpoint to set or change session RPE after `complete`.
- No endpoint to attach a `meal_photo` media asset to an existing meal log.
- Written against `main` at `2c9819d3`. Re-check each item on the latest `main` before building; drop what is done and say so in the PR (AGENTS.md).
