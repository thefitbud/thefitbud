## Outcome
The five render tests that each failed once on 25 Nov 2026, then passed on a re-run, are deterministic: they do not depend on real timers, unawaited updates, or render order. A later CI run of the same tests on a quiet machine is expected to pass every time. Product behaviour stays the same unless a test cannot be fixed without a tiny, behaviour-preserving change in a file this task owns.

## Acceptance criteria
- [ ] Each of the five tests is deterministic: use fake timers or `waitFor` / `findBy` for the state they assert, no `setTimeout` races against real time, no asserting a mock call count before the update has flushed. If a test needed a product change, the change does not alter what the user sees and is in a file this task owns.
- [ ] The assertion each test is making stays meaningful (do not delete the test or weaken it to `expect(true)`). The ClientLogMeal test still proves the entry key is reused after a 5xx and the "Logged by you" toast fires; the review test still proves the same resolve key is reused and a note is not sent again; the Today test still proves the skeleton stays until day, plan and week have answered; keptTabsLeave still proves a sheet does not stay live after a notification switches tab; ConfigureCoaching still proves an in-place target save of an active version does not create a new version (10000, not a stale 8000).
- [ ] `TraineeShell.tsx` is not modified in this task.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.
