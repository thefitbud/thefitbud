## Outcome
Acting on a Home row updates only that section and its count, with no skeleton flash, no scroll jump and no row reappearing during Undo; Home polls every 45 seconds only while the tab is visible.

## Context
- Covers master-list (v13) items HM2. Everything the implementer needs from those rows is pasted here.
- Cause (v13 HM2): one load function refetches every Home endpoint and replaces every section's state on each mutation, realtime hint and poll.
- Target: a `useHomeSections` hook with one fetcher per section (attention, asks, check-ins, renewals, getting started, reviewed) and its count; mutations apply an optimistic local change, then refetch only the affected section. Poll 45 s, paused on `document.hidden`, refetch on `visibilitychange`/focus. Rows hidden during the 5 s Undo stay hidden until Undo expires or is used.
- Design guide for every UI task: `docs/design/README.md` (v3 rules and the frame index), `docs/design/DESIGN-NOTES.md` (palette, type, spacing, components, data and time), `docs/design/DECISIONS-21OCT.md`, and the screen spec in `docs/spec/`. Dates read like "Wed 21 Oct" (never ISO), enums always go through `labelFor` (`packages/core/src/labels.ts`), touch targets are at least 44 pt / 44 px, counts and kcal use tabular numbers.
- Design-review step (W11 Z11-1): after capturing, run `node scripts/qa/visual/diff.mjs --task <ID>` on the captures and attach the generated `docs/qa/<ID>/design-review.md` to the PR. A frame difference the spec does not explain is fixed or listed in the PR as a follow-up, never silently left. **Until Z11-1 is on `main`** (it now runs in W11, after this batch — PLAN-v2 D-P2-7), skip the script: the reviewer's visual check compares the captures with the frames side by side, and the PR says "design-review tool not on main yet".

## Acceptance criteria
- [ ] One mutation triggers exactly one section fetch (+ its count) — asserted with a fetch spy.
- [ ] No skeleton after first load; scroll position unchanged after a mutation (test with a fixed `scrollY`).
- [ ] A row resolved with Undo pending never reappears from a poll inside the 5 s window.
- [ ] Poll interval 45 s; no fetch while `document.hidden`; one fetch on becoming visible.
- [ ] Realtime hints map to the matching section only.
- [ ] No ISO dates, raw enum values, percentages or streaks on the changed screens; `docs/spec/banned-strings.json` passes.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` pass.
